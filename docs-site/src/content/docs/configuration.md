## Adding DLNA Receiver to Music Assistant

1. Open **Music Assistant → Settings → Plugins**.
2. Click **Add Provider** and select **DLNA Receiver**.
3. Follow the on-screen instructions to configure the provider.

## Connection Parameters

| Parameter | Value |
|:----------|:------|
| **Service** | [https://github.com/trudenboy/ma-provider-dlna-receiver](https://github.com/trudenboy/ma-provider-dlna-receiver) |
| **Authentication** | None |
| **Max Audio Quality** | Source quality (passthrough) |

See the provider configuration dialog in Music Assistant for details on all available parameters.
